⚡ End-to-End RAG Ingestion & Retrieval Flow

Step 01
Document Ingestion
User uploads PDF, Markdown, or TXT. The document loader extracts raw text and applies overlapping window chunking (default: 800 chars, 150 overlap).
Step 02
Embedding Generation
Batch embeddings are generated via text-embedding-004 producing 768-dimensional normalized vectors for each chunk.
Step 03
Dual Vector Store
Persisted into either Cloud SQL (PostgreSQL + pgvector) with HNSW cosine indexes, or Cloud Firestore using native Vector fields.
Step 04
Grounded Agent QA
When a user asks a question, the ADK Agent invokes the search_documents tool to retrieve top-k chunks and synthesizes an answer with citations.

🗄️ Dual Vector Backend Implementations

Cloud SQL for PostgreSQL

VECTOR_BACKEND=cloudsql
~$8 – $10 / mo

Relational PostgreSQL database instance running on a cost-effective db-f1-micro tier with native pgvector extension. 

-- Auto-initialized Schema
CREATE EXTENSION IF NOT EXISTS vector;

CREATE TABLE document_chunks (
    id TEXT PRIMARY KEY,
    doc_id TEXT,
    filename TEXT,
    chunk_index INT,
    content TEXT,
    metadata JSONB,
    embedding vector(768)
);

CREATE INDEX ON document_chunks 
USING hnsw (embedding vector_cosine_ops);
  • HNSW index for sub-millisecond approximate nearest neighbor search
  • Connects via Cloud SQL Auth Proxy or direct VPC IP

Cloud Firestore Vector Search

VECTOR_BACKEND=firestore
Serverless Pay-Per-Op

Fully serverless NoSQL document database utilizing Google Cloud Firestore's native K-Nearest Neighbor (k-NN) vector search. 

# Native Vector Query
from google.cloud.firestore_v1.vector import Vector
from google.cloud.firestore_v1.base_vector_query import DistanceMeasure

query = coll.find_nearest(
    vector_field="embedding",
    query_vector=Vector(query_vec),
    distance_measure=DistanceMeasure.COSINE,
    limit=top_k
)
  • Zero idle cost when not querying (ideal for prototypes & scaling apps)
  • In-memory cosine ranking fallback if vector index is building

🔌 Gateway REST API Endpoints

Method Endpoint Auth Guard Description
POST /documents/upload Google OAuth Uploads PDF/TXT/MD, chunks content, generates embeddings, and saves to active vector store.
GET /documents Google OAuth Lists all indexed documents with chunk counts and upload timestamps.
DELETE /documents/{doc_id} Google OAuth Deletes a document and all corresponding vector chunks from the database.
POST /documents/search Google OAuth Executes direct vector similarity search and returns scored chunk snippets.
POST /chat Google OAuth Executes grounded RAG reasoning turn with automatic source citations.
GET /health Public Returns status of Gateway, Active Vector Store connection, and Agent Engine.
